# Examples

Real outputs from Founder OS skills — not placeholders. Each folder shows an
actual run: the input, and the output the skill produced.

| Example | Skill | Shows |
|---|---|---|
| [`founder-mode/`](founder-mode/) | `founder-mode` | A 90-day operating plan for a 2-person AI startup |
| [`fix-my-ui/`](fix-my-ui/) | `fix-my-ui` | An ugly analytics dashboard → premium redesign brief |
| [`saas-launch-kit/`](saas-launch-kit/) | `saas-launch-kit` | A full launch system for an AI inbox tool |
| [`startup-roast/`](startup-roast/) | `startup-roast` | A brutally honest landing-page teardown |
| [`viral-carousel/`](viral-carousel/) | `viral-carousel` | An 8-slide LinkedIn carousel package |
| [`production-ready/`](production-ready/) | `production-ready` | A prototype → production audit |
| [`ai-agent-architect/`](ai-agent-architect/) | `ai-agent-architect` | A support-triage agent system design |
| [`enterprise-saas-audit/`](enterprise-saas-audit/) | `enterprise-saas-audit` | An enterprise-readiness gap analysis |

Browse from the CLI:

```bash
founderos examples            # list all
founderos examples fix-my-ui  # one skill
```
