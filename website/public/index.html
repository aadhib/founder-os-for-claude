Installable in one command

The CLI detects your tools, validates your environment, and places skills where they belong.

npmnpx founder-os install
pnpmpnpm dlx founder-os install
bunbunx founder-os install
curlcurl -fsSL https://raw.githubusercontent.com/aadhib/founder-os-for-claude/main/install/install.sh | bash
  1. Refuse root, then detect Claude Code, Cursor, Codex & Gemini
  2. Validate Node, package manager & OS
  3. Path-validate & back up — then place skills
  4. Run doctor & print next steps

No clone. No ZIP. No manual copying. Preview first with npx founder-os install --dry-run · audit with founder-os doctor --security.

Secure by design

Built to be safe to run on day one — no elevation, no surprises.

🔒

No elevation

Installers refuse root / Administrator and only write inside your home directory.

🛡️

Path-validated writes

System directories and the home root are hard-refused. Symlinked targets are never followed.

💾

Backups before overwrite

--force copies the existing folder to a timestamped backup first.

📦

No install-time code

No postinstall hook. Published to npm with build provenance.
