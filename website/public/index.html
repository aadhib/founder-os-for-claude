01 — What it is

A workflow system, not a prompt pack.

Most "prompt packs" are a folder of .txt files. Founder OS is a real developer platform: every skill ships with a workflow engine, an output schema, a quality checklist, and documented anti-patterns — and a CLI that wires them into your tools properly.

⚙️

Structured skills

Each of the 8 skills is a documented system — purpose, operating principles, a step-by-step workflow engine, and a concrete output schema. Deterministic, not vibes.

🧰

A real CLI

A strict-TypeScript CLI detects your environment, validates it, places skills in the right per-tool directories, and tracks everything in a manifest.

🌐

Cross-tool, cross-OS

Claude Code, Cursor, Codex CLI and Gemini CLI — on macOS, Linux and Windows. One install, everywhere you work.

🔒

Safe by design

No elevation, path-validated writes, automatic backups, dry-run everything, no install hooks, no telemetry. Safe to run on day one.

02 — The skills

Eight skills. One operating system.

Strategy, design, growth, engineering — each skill is calibrated to a real founder problem and ends with an output you can act on today.

🧭strategy

founder-mode

Your AI COO + CTO + Product Strategist. Turns fuzzy intent into a ranked, sequenced operating plan — roadmaps, prioritization, GTM, pricing — where every recommendation carries an assumption and a kill criterion.

🎨design

fix-my-ui

Drop a UI screenshot, get a premium 2026 redesign brief: an 8-pillar audit scorecard, a corrected spacing / type / color system, region-by-region Tailwind specs, motion suggestions, and a shareable before/after narrative.

🚀growth

saas-launch-kit

An end-to-end launch system from one positioning statement: landing copy, pricing tiers, onboarding, lifecycle emails, a dated Product Hunt sequence, SEO scaffold, and analytics — all internally consistent.

🔥growth

startup-roast

A brutally honest, constructive teardown of your product and landing page: the 5-second test, a clarity teardown with verbatim quotes, a trust audit, a graded verdict, and a fix list ordered by leverage.

📱growth

viral-carousel

LinkedIn and Instagram carousels: five hook options, a narrative spine, slide-by-slide copy, caption, hashtags, concrete visual direction, and a paste-ready design prompt.

🛡️engineering

production-ready

Audits a prototype across 12 domains — security, auth, CI/CD, observability, database safety, scale — and returns a risk-ranked path to production with launch-blockers called out explicitly.

🤖engineering

ai-agent-architect

Designs production agent systems: topology, agent roles, a scoped tool / MCP layer, memory tiers, queues, failure handling, human-in-the-loop checkpoints, an eval harness, observability, and a safety review.

🏢engineering

enterprise-saas-audit

Runs the enterprise buyer's checklist on you — SOC2 posture, RBAC, SSO/SCIM, multi-tenancy, audit logs, data residency — and ranks every gap by deal impact with a sequenced roadmap.

03 — How it works

Install once. Ship better, every loop.

From a single command to a wired-up AI operator stack — and back to shipping.

  1. 1

    Install

    One command. The CLI bootstraps with no clone, no ZIP, no manual copying.

  2. 2

    Detect tools

    It finds Claude Code, Cursor, Codex CLI and Gemini CLI, by binary or config directory.

  3. 3

    Place skills

    Path-validated, symlink-safe, with automatic backups — into each tool's directory.

  4. 4

    Run a workflow

    /founder-mode, /fix-my-ui, /startup-roast — structured, repeatable, in your editor.

  5. 5

    Ship a better product

    Audit, fix, launch — then loop. founderos update keeps skills current.

04 — Install

One command. Every package manager.

No clone, no ZIP, no manual copying. The shell scripts refuse root, print the exact command, and confirm before doing anything.

Recommended — npm path

npx founderos install
pnpm dlx founderos install
bunx founderos install

Shell one-liners

curl -fsSL https://raw.githubusercontent.com/aadhib/founder-os-for-claude/main/install/install.sh | bash
irm https://raw.githubusercontent.com/aadhib/founder-os-for-claude/main/install/install.ps1 | iex

Cautious? Preview every change first with npx founderos install --dry-run — it writes nothing.

05 — The CLI

Eleven commands. Everything is inspectable.

Manage skills across every tool from one CLI — with dry-run and security audits built in.

founderos installInstall skills into your AI tools — wizard, --dry-run, --force.
founderos uninstallCleanly remove skills via the manifest. --dry-run, --restore.
founderos doctorEnvironment + manifest health check. --security for the audit.
founderos listList every skill and its install status.
founderos updateRe-sync installed skills with the latest catalog.
founderos initScaffold Founder OS into the current project.
founderos add <skill>Install a single skill.
founderos remove <skill>Remove a single skill.
founderos verifyValidate the skill catalog. --security audits content.
founderos examplesBrowse the bundled library of real example outputs.
founderos integrationsShow supported AI tools and detection status.

07 — Security

Safe to run on day one.

Founder OS only writes plain Markdown into AI-tool folders inside your home directory — and proves it.

🚫

No sudo / admin

The installers refuse to run elevated. The CLI never calls sudo.

🏠

Local-first

Everything stays on your machine. No accounts, no servers, no hosted dependency.

🛡️

Path-validated writes

Filesystem roots, system directories and symlink escapes are hard-refused.

💾

Backups before overwrite

--force copies the existing folder to a timestamped backup first.

👀

Dry-run everything

install --dry-run shows every planned change and writes nothing.

📡

No hidden telemetry

No tracking, no phone-home, no postinstall hook. The code is the spec.

Built-in audits — founderos doctor --security and founderos verify --security — check path safety, symlinks, manifest integrity, and confirm skills are plain documentation.
